# Aurora Finance Brand

A Frappe app providing the Aurora Finance brand identity including logo, favicon, and CSS theme overrides. The brand uses a navy (#0B1F3A) and teal (#1FB6A6) color palette with a custom "Aurora Finance" wordmark logo and "A" favicon. All brand assets are served as static assets and applied via `brand.css` which overrides Frappe's default primary colors for buttons, links, navbar, and other UI components.
